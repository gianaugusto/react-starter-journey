# Do Zero ao Primeiro Website em React

## Objetivo

Esta trilha foi criada para pessoas sem conhecimento prévio em desenvolvimento web.

Ao final do curso você será capaz de:

- Entender como a web funciona
- Utilizar Git e GitHub
- Criar páginas com HTML
- Estilizar aplicações com CSS
- Programar com JavaScript
- Criar APIs simples com Node.js
- Construir seu primeiro website em React
- Publicar sua aplicação online

Não iremos nos aprofundar em cada tecnologia neste momento.

O objetivo é construir uma visão geral do ecossistema Frontend e entregar projetos em todas as etapas.
