# Zero to First React Website

## Goal

This learning path was designed for people with no prior web development experience.

By the end of the course you will be able to:

- Understand how the web works
- Use Git and GitHub
- Build pages with HTML
- Style applications using CSS
- Program with JavaScript
- Create simple APIs using Node.js
- Build your first React website
- Deploy your application online

The focus is not mastering every technology.

The goal is to understand the ecosystem and deliver small projects throughout the journey.
