# Modulo 6 - JavaScript Basico

## Objetivo

Aprender logica de programacao e criar uma calculadora simples.

## Passo a passo

1. Revise os fundamentos:
   - Variaveis
   - Tipos
   - Condicionais
   - Loops
   - Funcoes
   - Arrays
   - Objetos
2. No arquivo `script.js`, crie funcoes para:
   - Somar
   - Subtrair
   - Multiplicar
   - Dividir
3. Teste no console do navegador.
4. Mostre os resultados na tela com elementos HTML.

## Entregavel

Calculadora simples com operacoes basicas funcionando.
