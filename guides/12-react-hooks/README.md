# Modulo 12 - React Hooks

## Objetivo

Conectar o frontend React ao backend usando hooks.

## Passo a passo

1. Use `useState` para armazenar lista de produtos.
2. Use `useEffect` para buscar dados da API ao carregar a pagina.
3. Crie formulario para adicionar produto.
4. Envie dados com `fetch` (POST) para o backend.
5. Atualize a lista apos criacao/remocao.

## Entregavel

Frontend React integrado ao backend.
