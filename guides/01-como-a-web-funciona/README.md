# Modulo 1 - Como a Web Funciona

## Objetivo

Entender o caminho entre usuario, navegador, internet e servidor.

## Passo a passo

1. Estude os conceitos basicos:
   - Cliente e servidor
   - HTTP e HTTPS
   - DNS
   - Requisicao e resposta
   - Status codes: 200, 404, 500
2. Abra o DevTools no Chrome (F12), guia Network.
3. Acesse um site e observe:
   - URL chamada
   - Metodo HTTP
   - Status da resposta
4. Crie um diagrama simples com este fluxo:

```text
Usuario -> Navegador -> Internet -> Servidor -> Resposta HTML
```

## Entregavel

Um diagrama (imagem ou markdown) explicando o fluxo de acesso a um website.
