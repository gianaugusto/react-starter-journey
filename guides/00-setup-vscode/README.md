# Setup Inicial (VS Code)

Este guia prepara seu ambiente para seguir toda a trilha usando o VS Code como ferramenta principal.

## Objetivo

- Instalar as ferramentas essenciais
- Configurar o VS Code para produtividade
- Criar a pasta do primeiro projeto

## Passo a passo

1. Instale o VS Code em https://code.visualstudio.com/
2. Instale o Git em https://git-scm.com/downloads
3. Instale o Google Chrome em https://www.google.com/chrome/
4. Abra o VS Code e instale as extensoes:
   - Portuguese (Brazil) Language Pack (opcional)
   - GitLens
   - Prettier
   - ESLint
   - Live Server
5. Abra o terminal do VS Code em Terminal > New Terminal
6. Crie a pasta do projeto no terminal:

```bash
mkdir meu-primeiro-site
cd meu-primeiro-site
```

7. Abra a pasta no VS Code com File > Open Folder
8. Crie um arquivo chamado `README.md` na pasta para anotar seu progresso

## Checklist

- VS Code instalado
- Git instalado
- Chrome instalado
- Pasta `meu-primeiro-site` criada
- Terminal do VS Code funcionando
