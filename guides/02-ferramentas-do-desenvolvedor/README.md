# Modulo 2 - Ferramentas do Desenvolvedor

## Objetivo

Dominar as ferramentas de base para programar com eficiencia.

## Passo a passo

1. Abra o VS Code na pasta do projeto.
2. Abra o terminal integrado e rode:

```bash
pwd
ls
```

3. Abra o Chrome e teste o DevTools (F12).
4. Crie os arquivos iniciais:

```bash
touch index.html styles.css script.js
```

5. Use a extensao Live Server para abrir `index.html` em modo local.

## Entregavel

Projeto com os 3 arquivos base (HTML, CSS, JS) abrindo no navegador.
