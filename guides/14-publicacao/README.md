# Modulo 14 - Publicacao

## Objetivo

Publicar frontend e backend para acesso pela internet.

## Passo a passo

1. Suba o codigo no GitHub.
2. Frontend no Vercel:
   - Importe repositorio
   - Configure build do projeto React
   - Publique
3. Backend no Render:
   - Crie novo Web Service
   - Conecte repositorio
   - Configure start command
4. Ajuste URL da API no frontend para o backend publicado.
5. Teste a aplicacao online.

## Entregavel

Aplicacao acessivel na internet com frontend e backend online.
