# Modulo 7 - JavaScript e DOM

## Objetivo

Criar uma aplicacao interativa de lista de tarefas usando manipulacao do DOM.

## Passo a passo

1. Monte o HTML com:
   - Input de tarefa
   - Botao adicionar
   - Lista `ul`
2. No JavaScript, capture eventos de clique e Enter.
3. Implemente funcoes:
   - Adicionar tarefa
   - Remover tarefa
   - Marcar como concluida
4. Atualize o DOM dinamicamente para refletir mudancas.
5. Opcional: salve tarefas no `localStorage`.

## Entregavel

To-do list funcional com adicionar, remover e concluir tarefa.
