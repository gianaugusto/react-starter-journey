# Modulo 13 - Projeto Final

## Objetivo

Construir um catalogo de produtos full stack.

## Escopo

- Backend: Node.js + Express
- Frontend: React

## Passo a passo

1. Planeje o modelo de produto (id, nome, preco, descricao).
2. Implemente backend com rotas:
   - GET /products
   - POST /products
   - DELETE /products/:id
3. No React, crie telas para:
   - Listar produtos
   - Adicionar produto
   - Remover produto
4. Teste o fluxo completo: criar, listar e remover.
5. Revise UX minima (mensagens de erro e carregamento).

Aplicacao full stack funcionando localmente.
