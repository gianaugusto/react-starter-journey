# Modulo 8 - Consumo de APIs

## Objetivo

Consumir dados externos e exibir no frontend.

## Passo a passo

1. Escolha uma API publica (Pokemon, clima ou usuarios).
2. Crie uma requisicao GET com `fetch`.
3. Converta resposta para JSON.
4. Renderize os dados no HTML.
5. Trate erros com `try/catch` e feedback visual.

## Entregavel

Pagina exibindo dados vindos de API externa.

## Recursos gratuitos

- MDN Fetch API: https://developer.mozilla.org/pt-BR/docs/Web/API/Fetch_API
- Public APIs: https://github.com/public-apis/public-apis
- Video (YouTube): https://www.youtube.com/results?search_query=fetch+api+javascript+iniciantes
