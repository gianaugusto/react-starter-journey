# Modulo 4 - HTML

## Objetivo

Construir sua primeira pagina pessoal com estrutura semantica.

## Passo a passo

1. Crie a estrutura basica do HTML com `<!DOCTYPE html>`.
2. Adicione no corpo da pagina:
   - Nome (h1)
   - Foto (img)
   - Bio (p)
   - Hobbies (ul/li)
   - Contato (a)
3. Salve e abra no navegador.
4. Corrija erros com o DevTools e validadores.

## Entregavel

Pagina pessoal com nome, foto, bio, hobbies e contato.

- Validador W3C: https://validator.w3.org/
