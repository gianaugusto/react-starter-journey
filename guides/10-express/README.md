# Modulo 10 - Express

## Objetivo

Criar uma API de produtos com rotas e middleware.

## Passo a passo

1. Dentro da pasta do backend, instale o Express:

```bash
npm install express
```

2. Crie `app.js` com:
   - Middleware `express.json()`
   - Rota `GET /products`
   - Rota `POST /products`
3. Use um array em memoria para armazenar produtos.
4. Rode o servidor e teste com Insomnia ou Postman.

## Entregavel

API CRUD basica com pelo menos GET e POST funcionando.
