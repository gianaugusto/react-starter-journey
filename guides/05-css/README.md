# Modulo 5 - CSS

## Objetivo

Transformar a pagina pessoal em uma landing page visualmente organizada.

## Passo a passo

1. Conecte `styles.css` ao HTML.
2. Defina estilos base:
   - Fonte
   - Cor de fundo
   - Cor do texto
3. Use classes para estilizar secoes e botoes.
4. Organize layout com Flexbox.
5. Crie cartoes para destacar informacoes.
6. Ajuste espacamentos e alinhamento.

## Entregavel

Landing page com cores, botoes, cartoes e layout centralizado.
