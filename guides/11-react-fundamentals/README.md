# Modulo 11 - React Fundamentals

## Objetivo

Criar a primeira aplicacao React usando componentes e estado.

## Passo a passo

1. Crie o projeto React com Vite:

```bash
npm create vite@latest frontend -- --template react
cd frontend
npm install
npm run dev
```

2. Estruture componentes:
   - Header
   - Footer
   - ProductCard
3. Entenda JSX, props e state no fluxo da aplicacao.
4. Estilize componentes para melhorar leitura.

## Entregavel

Aplicacao React inicial com componentes reutilizaveis.
